# CC2025camera

## 概要
ブラウザ上でカメラ映像にストップウォッチを重ねて撮影/録画できるシンプルなWebアプリです。

## 使い方
1. [index.html](index.html) をブラウザで開きます。
2. カメラ/マイクの利用許可を求められたら許可します。
3. タイマー開始/停止、写真撮影、録画開始/停止を操作します。

## 権限について
- 本アプリは `getUserMedia` を使用してカメラとマイクにアクセスします。
- 権限はブラウザの確認ダイアログで許可/拒否できます。
